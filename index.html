THE QUICK GUIDE

Small swaps.
Big trouble.

  1. Move & swap. Move the two-block cursor and swap neighbors. Match 3 or more in a row or column.
  2. Keep it low. Your stack rises over time. Raise it yourself when you need fresh blocks. Reach the ceiling for too long and you're out.
  3. Send some pressure. Clear 4+ blocks for a combo. Set up falling blocks to match again for a chain. Both send garbage to Blue.
  4. Turn it around. Match beside garbage to convert it into blocks. Match special ! blocks to send metal garbage.
