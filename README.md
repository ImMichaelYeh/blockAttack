# Block Attack

An original rising-panel puzzle battler planned for CPU versus, local two-player, and LAN two-player play.
Red is Player 1; Blue is Player 2.

See [PLAN.md](PLAN.md) for the inspected source inventory, menu flow, original visuals/audio direction,
controls, LAN architecture, implementation milestones, and acceptance checks.

Implementation belongs in this repository. The existing `../tetrisAttack` game is a read-only reference
for reusable engine code and tests; its character assets, music, story, and generated bundles are excluded.

Current status: planning complete; no playable game or install/run scripts yet.
